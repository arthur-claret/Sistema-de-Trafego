# 🚦 Simulador de Cruzamento de Trânsito em C

## Sobre o projeto

Este projeto foi desenvolvido como trabalho acadêmico para a disciplina de Programação em C, no **1º semestre de 2026**. O desafio proposto pelo professor foi registrar em código um sistema de tráfego de carros, simulando o comportamento de veículos em um cruzamento controlado por semáforos.

O código foi desenvolvido em **14 dias** e a simulação roda diretamente no terminal, com renderização em tempo real usando *ANSI escape codes* para cores e controle de tela.

## Funcionalidades

- 🚗 Movimentação automática de múltiplos carros pelo cruzamento
- 🚦 Semáforos com ciclos sincronizados de vermelho, amarelo e verde
- 🚶 Sinais de pedestre integrados ao ciclo dos semáforos
- 🔄 Reposicionamento automático dos carros ao saírem da tela
- 🎨 Renderização colorida via terminal (ANSI escape codes)

## Tecnologias utilizadas

- **Linguagem C**

## Como executar

```bash
gcc simulador.c -o simulador
./simulador
```
