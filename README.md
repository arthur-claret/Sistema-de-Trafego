# Simulador de Cruzamento

Simulação de um cruzamento com semáforos e carros em movimento, 
renderizada diretamente no terminal usando códigos ANSI para cores.

## Tecnologias
- Linguagem C
- ANSI escape codes (cores e controle de tela)

## Como executar

\`\`\`bash
gcc main.c -o simulador
./simulador
\`\`\`

## Funcionalidades
- Semáforos com ciclos de vermelho/amarelo/verde
- Sinais de pedestre sincronizados
- Múltiplos carros com movimento automático
